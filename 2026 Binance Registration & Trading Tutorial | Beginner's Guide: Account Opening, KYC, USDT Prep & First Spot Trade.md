## 5. What is KYC Identity Verification?

KYC = platform confirms the account is used by its real owner. Requires:
- Real full name
- Date of birth
- Country/Region
- ID document (passport/ID/driver's license)
- Clear document photos
- Facial recognition

After KYC, you typically unlock: deposit, withdrawal, C2C, spot, futures, Earn, Launchpool, Web3 wallet, etc. To fully use Binance, **do not skip KYC**.

---

## 6. How to Complete KYC

1. Log in → Go to Identity Verification
2. Select country/region
3. Fill in personal info (name/DOB, exact match to ID)
4. Upload ID front/back (all 4 corners, no glare, no crop, no edit)
5. Complete facial scan (remove hat/glasses, good lighting)
6. Wait for review (minutes to hours)

**Pre-submit checklist**:
- ✅ Name matches ID
- ✅ ID is valid
- ✅ Photo clear, unobstructed
- ✅ All 4 corners visible
- ✅ No glare
- ✅ Good lighting for face scan

❌ No one else's ID. No edited images. No covered info.

---

## 7. Why KYC Fails

| Common Cause | Fix |
|--------------|-----|
| Blurry photo | Retake with good lighting |
| Glare on document | Adjust angle, avoid direct light |
| Corners cut off | Step back, include all edges |
| Name mismatch | Match ID exactly (pinyin/characters) |
| Wrong DOB | Double-check ID |
| Wrong region | Select correct issuing/residence region |
| Someone else's ID | Must be your own |
| Face scan fails | Remove hat/glasses, better light, no beauty filter |
| Network dropped | Switch connection, retry |
| Edited photo | Use original unedited image |

## 9. First Trade Should Be Spot

Spot = use USDT to buy BTC/ETH/BNB/SOL etc. Assets sit in your spot wallet. Price fluctuations affect value, but **no liquidation mechanism** (unlike futures).

**Spot buy steps** (BTC/USDT example):
1. Go to Spot Trading
2. Search BTC/USDT
3. Select "Buy"
4. Choose order type (Market / Limit)
5. Enter USDT amount
6. Confirm pair, side, amount, fee
7. Submit order
8. Check asset in "Spot Wallet"

> 🎯 First trade goal = learn the complete process, not make money.

## 10. Market Order vs Limit Order

| Type | Feature | Best For |
|------|---------|----------|
| Market | Executes immediately at current price | Beginners, small test amounts |
| Limit | Set your own buy price, executes when price hits | Those who want precise entry |

New users: start with a small market order to learn the interface. Once you understand how orders fill, how balances update, and how fees are calculated, then study limit orders.

---

## 11. Why Be Careful with Futures

Futures are NOT simple coin buying. They involve: long/short, leverage, margin, funding rate, isolated/cross margin, liquidation price, TP/SL.

**Common fatal newbie mistakes**:
- ❌ Open futures right after registering
- ❌ Use high leverage immediately (50x/125x)
- ❌ Put all funds in one position
- ❌ Don't know liquidation price
- ❌ No stop-loss
- ❌ Emotionally add to losing positions
- ❌ Can't tell spot from futures

> ⚠️ Advice: Learn spot first → Understand futures mechanics → Practice on demo → Then small real-money trades. Never start with heavy leverage.

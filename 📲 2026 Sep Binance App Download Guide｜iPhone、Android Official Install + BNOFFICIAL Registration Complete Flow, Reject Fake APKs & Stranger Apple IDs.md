Path: Assets → Deposit → Deposit Crypto → USDT → Select Network → Copy address.

**Iron Rule: Sender Network = Binance Receive Network**
- Binance shows TRC-20 (TRON) → Sender must also select TRON
- Binance shows ERC-20 (Ethereum) → Sender must also select Ethereum

**First deposit suggestion: 10–20 USDT test to confirm arrival, then transfer large amounts.** Paying one extra on-chain fee is far cheaper than losing funds to wrong-network transfer.
